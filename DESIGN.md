# Libeen Lead Intake — sistema visual

La herramienta toma como referencia la web oficial de Libeen: fondo blanco, texto azul marino, acento coral y una voz directa y cercana. La composición está adaptada a la lectura y revisión de expedientes, con densidad suficiente para el trabajo diario.

- **Tipografía:** Manrope cuando está disponible y familia de sistema como alternativa; títulos compactos y texto operativo legible.
- **Color:** azul marino `#001233` para texto, coral para identidad y un coral más oscuro en botones para mejorar el contraste. Los estados de atención y error tienen colores diferenciados.
- **Composición:** conversación como transcripción y ficha comercial como filas, con evidencia desplegable y acciones humanas junto a sus fuentes.
- **Interacción:** acción principal redondeada inspirada en la web oficial; controles secundarios discretos, foco visible y compatibilidad con movimiento reducido.
- **Seguridad:** declaraciones no verificadas, incidencias y restricciones de exportación permanecen visibles y bajo control humano.
- **Adaptación:** en móvil, controles y filas se apilan manteniendo la fuente y las acciones accesibles.

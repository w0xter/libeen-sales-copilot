No despliegue obligatorio, permisos de GitHub sin autorización, vídeo ficticio ni cifras de productividad inventadas.

## 8. Technical requirements

Comandos y variables de entorno reales; documentación no puede afirmar un test no ejecutado; inspeccionar secrets y fixtures.

## 9. Constraints

No incorporar API keys ni datos reales; acceso al repo privado requiere aprobación. No presentar `AI_MODE=replay` como modelo real.

Reglas globales no dispensables: solo datos sintéticos; sin envío real ni aprobación financiera, con evidencia y revisión humana; trabajo limitado a su brief y rutas propias.

- [ ] Un evaluador puede arrancar la V0 desde clone limpio siguiendo el README y ejecutar las pruebas documentadas.

- [ ] El resultado incluye un handoff con archivos, evidencias, validación y riesgos.

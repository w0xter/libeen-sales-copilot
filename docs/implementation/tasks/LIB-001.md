## 1. Task ID

`LIB-001`. Antes de empezar, comprobar que todas las dependencias se hayan integrado y superado sus gates; trabajar en su propio worktree.

## 2. Objective

Completar el entorno del scaffold ya presente, sin implementar lógica comercial, para que todas las ramas compartan herramientas y verificaciones reproducibles.

## 3. User / business value

Elimina el coste de instalación repetida y protege los contratos y las claves antes de la primera oleada.

## 5. Scope

Instalar dependencias; crear `pnpm test`, `pnpm typecheck`; configurar test runner; preparar `.env.example` (con `OPENAI_MODEL=gpt-4.1-mini`, `AI_MODE=replay`, clave vacía); permitir `!.env.example` en gitignore; incorporar AGENTS aprobado sin borrar bloque Next.js.

## 6. Out of scope

Ni componentes de producto, ni facts, ni tareas de IA, ni CI grande, ni Docker, ni clave real.

No implementar funcionalidades no incluidas aunque sean técnicamente sencillas; preparar un Contract Change Request si se descubre una dependencia real nueva.

## 7. Functional requirements

El repo base sigue arrancando; OpenAI no se activa sin clave; replay es modo explícito, no fallback silencioso.

## 8. Technical requirements

Fijar dependencias en lockfile; cargar variables solo servidor; comprobar scripts con la versión de Next local; incluir una prueba real en lugar de un runner vacío.

## 9. Constraints

No guardar credenciales ni exponer NEXT_PUBLIC_OPENAI_API_KEY. No reemplazar el bloque BEGIN/END de Next.js. Evitar modificar código de dominio.

Reglas globales no dispensables: solo datos sintéticos; sin envío real ni aprobación financiera, con evidencia y revisión humana; trabajo limitado a su brief y rutas propias.

- [ ] Dependencias instaladas de manera reproducible y script `pnpm typecheck` ejecutable.
- [ ] `pnpm test` ejecuta al menos una prueba verdadera; no usar `--passWithNoTests` como simulación de gate.
- [ ] `.env` sigue ignorado, `.env.example` sí se versiona y no contiene secretos.
- [ ] El `AGENTS.md` aprobado se instala preservando el bloque de Next.js.
- [ ] Todos los cambios observables tienen tests apropiados (si aplica); los fallos y áreas no probadas están documentados.
- [ ] El resultado incluye un handoff con archivos, evidencias, validación y riesgos.

En la rama real: `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`; `git check-ignore -v .env`; registrar resultados observados.

No asumir que todos los comandos existen: LIB-001 crea `pnpm test` y `pnpm typecheck`; ejecutar los realmente disponibles y reportar outputs verdaderos.
